My ex, in one word:

> **Unsubscribed**

One word, twelve characters, no punctuation tricks: the ex as a
newsletter you finally cancelled — no more updates, no renewal,
no "we miss you" emails. The joke lands with the word itself, and
anyone who has ever hit unsubscribe on a person feels the nod.

## Run

```sh
node main.ts
```

The program writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), prints it to stdout, and runs a
self-checking gate first (1–111 characters, single line, exactly one
word) that exits non-zero before writing on failure.
